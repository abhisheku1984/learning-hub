# THE LEARNING HUB — AI TOOL GUIDE
### The 20-tool stack: what each tool does, best use, level and workflow
Free resource from The Learning Hub — https://abhisheku1984.github.io/learning-hub/

Pricing changes often — always verify current plans on each tool's official site before committing.

---

## TEXT AI
**ChatGPT** — Conversational drafting and analysis. Best for: writing, brainstorming. Level: Beginner. Workflow: Idea → draft → refine. Pricing: Free/Paid (verify).
**Claude** — Long-document reading, writing and reasoning. Best for: reports, analysis. Level: Beginner. Workflow: Upload doc → ask → refine. Pricing: Free/Paid (verify).

## IMAGE AI
**Midjourney** — Generates images from text. Best for: concept art, visuals. Level: Intermediate. Workflow: Prompt → variations → upscale. Pricing: Paid (verify).
**Leonardo AI** — Image generation with style control. Best for: brand visuals. Level: Beginner. Workflow: Prompt → pick style → export. Pricing: Free/Paid (verify).

## VIDEO AI
**Runway** — Generates and edits video. Best for: short clips. Level: Intermediate. Workflow: Script → clip → edit. Pricing: Free/Paid (verify).
**Pika** — Text and image to short video. Best for: social clips. Level: Intermediate. Workflow: Image → motion → trim. Pricing: Free/Paid (verify).

## VOICE AI
**ElevenLabs** — Realistic text to speech. Best for: voiceovers. Level: Beginner. Workflow: Script → voice → export. Pricing: Free/Paid (verify).
**HeyGen** — Talking avatar videos with voice. Best for: explainers. Level: Intermediate. Workflow: Script → avatar → render. Pricing: Paid (verify).

## RESEARCH AI
**Perplexity** — Answers with cited sources. Best for: fast research. Level: Beginner. Workflow: Question → sources → brief. Pricing: Free/Paid (verify).
**Elicit** — Finds and summarises papers. Best for: literature reviews. Level: Intermediate. Workflow: Question → papers → table. Pricing: Free/Paid (verify).

## CODING AI
**GitHub Copilot** — Code suggestions in editor. Best for: faster coding. Level: Intermediate. Workflow: Comment → code → test. Pricing: Paid (verify).
**Cursor** — AI code editor that edits your project. Best for: building apps. Level: Advanced. Workflow: Describe → generate → test. Pricing: Free/Paid (verify).

## PRESENTATION AI
**Gamma** — Builds decks from outlines. Best for: quick presentations. Level: Beginner. Workflow: Outline → deck → polish. Pricing: Free/Paid (verify).
**Beautiful.ai** — Smart slide layouts. Best for: clean decks. Level: Beginner. Workflow: Content → layout → present. Pricing: Paid (verify).

## AUTOMATION AI
**Zapier** — Connects apps in workflows. Best for: repeated tasks. Level: Intermediate. Workflow: Trigger → action → notify. Pricing: Free/Paid (verify).
**Make** — Visual workflow builder. Best for: multi-step automations. Level: Advanced. Workflow: Trigger → modules → output. Pricing: Free/Paid (verify).

## PRODUCTIVITY AI
**Notion AI** — Summaries and notes in your workspace. Best for: knowledge base. Level: Beginner. Workflow: Notes → summary → tasks. Pricing: Paid (verify).
**Motion** — Auto-schedules tasks. Best for: calendar planning. Level: Beginner. Workflow: Tasks → schedule → adjust. Pricing: Paid (verify).

## DESIGN AI
**Canva** — Design with AI assist. Best for: posters, social posts. Level: Beginner. Workflow: Brief → layout → export. Pricing: Free/Paid (verify).
**Figma AI** — Design assist inside Figma. Best for: UI drafts. Level: Intermediate. Workflow: Prompt → layout → refine. Pricing: Free/Paid (verify).

---

## How to pick your first three
1. **One writing/thinking tool** (ChatGPT or Claude) — use daily.
2. **One research tool** (Perplexity) — for anything you must verify.
3. **One automation or presentation tool** (Zapier or Gamma) — for visible wins at work.
