## BEFORE YOU APPLY
- [ ] Save the full job description as text — you'll check every application against it.
- [ ] Mirror the exact job title in your headline or summary (e.g. "Workforce Analyst" if that's what the ad says).
- [ ] Pick one resume layout and keep it ATS-friendly: standard headings (Experience, Skills, Education), no tables, text boxes or graphics in critical content.

## KEYWORD MATCH
- [ ] List the hard skills from the job description (tools, methods, certifications).
- [ ] Check each one appears in your resume — in the Skills section and inside at least one experience bullet where true.
- [ ] Add missing terms ONLY where they are genuinely true for you. Never invent skills.
- [ ] Include both forms where natural: "Excel (advanced)" and "Power BI", "forecasting" and "capacity planning".

## EXPERIENCE BULLETS
- [ ] Start every bullet with an action verb (built, led, automated, reduced, delivered).
- [ ] Add scope: team size, budget, volume, frequency.
- [ ] Add a measurable result where one exists — do not invent numbers. Use "improved processing time by streamlining X" if you lack the exact figure.
- [ ] Rewrite weak bullets with the Prompt Lab's "Resume bullet rewriter" prompt.

## STRUCTURE CHECK
- [ ] Clear **Skills** heading exists (ATS systems look for it).
- [ ] **Experience** and **Education** headings use standard names.
- [ ] Summary is 2–3 lines, tailored to this role, no clichés ("hardworking team player").
- [ ] Dates are consistent (MM YYYY) and in reverse-chronological order.

## LINKEDIN ALIGNMENT
- [ ] Headline says what you do + who you help (use the "LinkedIn headline" prompt).
- [ ] About section matches the resume story in first person, ~150 words.
- [ ] Skills section on LinkedIn mirrors the resume's top skills.

## FINAL PASS
- [ ] Run the in-browser optimizer: keyword match rising with each edit is your signal.
- [ ] Read it aloud once — typos hide in silence.
- [ ] Export as PDF unless the application explicitly asks for DOCX.

**Remember:** the optimizer's scores are estimates based on keyword matching. A human still reads your resume — clarity beats cleverness.
